# 第七輪（之後再做）：霧屍斷腳爬行影格

遊戲裡已經有肢體破壞（程式在 `src/art/ZombieGore.ts`、機率在 `src/data/zombies.ts` 的 `GORE`）：

- 斷手：執行期把伸在前面的前臂挖掉、斷口塗暗紅，霧屍照樣走，攻擊力減半
- 斷腳：腿飛出去，霧屍改成爬行
- 爆頭：頭整個炸成碎片和血霧，屍體沒有頭

斷手和爆頭用現有影格切出來就夠了。**斷腳爬行目前是暫代**：拿受擊影格第 21、22 格（躺著、撐起上身）切掉腿、左右翻轉，看起來像「仰躺著用手肘拖」。真正的趴姿爬行要用 H3 做。

## 要交的東西

`art/ai/out/zombie_crawl/crawl.png`：**4 格橫排，每格 64×64**，透明底，規格和 `ZOMBIE_REACT.md` 完全一樣（朝右、同一套 70 色調色盤、分區顏色要保住）。

| 格 | 內容 |
| --- | --- |
| 0 | 趴在地上、腰以下沒有了（斷口在左邊），頭抬起來看前方，右手往前伸 |
| 1 | 右手抓地往前拖，身體往前一點 |
| 2 | 換左手往前伸 |
| 3 | 左手抓地往前拖 |

- 身體貼地：胸口、肚子的底部在 y = 60–62，頭頂大約在 y = 38–42
- 斷口畫成破掉的上衣下襬加一點暗紅，不要畫骨頭特寫
- 簡易 GIF 就好（3 倍、8 fps、循環兩次）

## 生成方式

首尾幀都用「趴地伸手」的同一張圖（可以先拿第 21 格躺姿改成趴姿當首幀），提示詞方向：legless zombie crawling on its belly, dragging itself forward with its arms, side view, fixed camera, plain magenta background, pixel art。從影片挑 4 格，後處理和第五輪相同。

接進遊戲（換掉暫代的 21、22 格、對上爬行節奏）由雲端這邊做。
