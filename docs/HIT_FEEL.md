# 打擊回饋與受力感規劃（街機動作遊戲手感）

目標：揮一棒要「打到肉」——出手有預備、命中瞬間有停頓與震動、被打的一方有明顯的受力反應（後仰、被打飛、落地彈起、滑行），整串動作節奏清楚。參考的是街機清版動作遊戲的做法。

## 1. 現況盤點

系統面已經有不少基礎，缺的主要是**被打的一方的反應**與**動作和停頓的同步**。

| 項目 | 現況 | 程式位置 |
| --- | --- | --- |
| 卡肉（hit-stop） | 有：命中時全畫面停 `hitStop`＋（多隻、擊殺、收尾）加成；鋁棒 50 ms | `MeleeSystem` → `Fx.freeze()` |
| 鏡頭震動、推鏡 | 有：trauma＋往打擊方向 kick | `CameraFeel` |
| 手把震動 | 有 | `rumble()` |
| 擊退、硬直 | 有：數值擊退＋滑行、`stagger` 秒數；霧屍有 `knockbackResist`／`staggerResist` | `Zombie.takeDamage()`、`stagger()` |
| 受擊表現 | 只有：閃白、擠壓、往後傾斜幾度 | `Fx.squash()`、`hitLean` |
| 打擊特效 | 有：血、`meleeImpact`（slash／heavy-slash／blunt） | `Fx` |
| 連擊數、處決字樣 | 有 | `MeleeSystem.showStreak()` |
| 攻擊者動作 | 剛接上 H3 影格：預備 2、出手 1、收招 3，依時間比例切格 | `Player.setMeleePose()` |
| 擊殺倒地 | 有：倒地影格或程式轉 90° | `Fx.fall()` |

## 2. 缺口（為什麼還不像街機）

1. **命中那一刻畫面停住，但阿凱不一定停在「球棒打到」那一格**：現在依時間比例選格，停頓可能落在預備或收招。
2. **被打的霧屍沒有受擊動作**：只是傾斜和閃白，看起來像紙板被推。
3. **停頓時沒有「抖」**：街機的招牌是卡肉期間被打的人原地快速左右抖，攻擊者不抖。
4. **擊退只有一種**：輕打重打都是往後滑，缺少「被打飛 → 落地彈 → 滑行 → 爬起」的重擊反應。
5. **打中和揮空收招一樣長**：街機通常打中可以接下一招（或收招變短），揮空要吃完整破綻，打中才有「爽」的回報。
6. **打擊火花偏小**：缺少大而短（2–3 幀）的白芯衝擊閃光。
7. **被打飛的霧屍不會撞到別人**：清版遊戲的爽感很大一部分來自「打一隻、倒一排」。

## 3. 方案

### A. 攻擊方（阿凱）

| # | 做法 | 說明 |
| --- | --- | --- |
| A1 | **固定命中格** | 揮擊 6 格裡定義一格「命中格」（第 3 格，球棒打到最前方）。命中時強制顯示這一格並在卡肉期間停住，卡肉結束才接收招 |
| A2 | **打中收招加速、揮空收招變長** | 打中：收招 ×0.7，且收招後半可以取消成下一棒或移動；揮空：收招 ×1.2 |
| A3 | **出手前衝與影格同步** | 現有 `lunge` 改在出手格才推進，預備格不動 |
| A4 | **揮擊弧光對齊球棒** | 現有 `trailColor` 弧光改用影格裡球棒尖端的位置畫，打中時弧光變亮一格 |

### B. 受擊方（霧屍）

| # | 做法 | 說明 |
| --- | --- | --- |
| B1 | **卡肉抖動** | 卡肉期間被打的霧屍左右抖 ±2 px（每 30 ms 換邊），攻擊者不動 |
| B2 | **閃白 → 紅 → 正常** | 第 1 幀全白、第 2 幀偏紅、之後回正 |
| B3 | **受擊動作影格**（需要新美術） | 每種霧屍 3 格：被打到頭往後甩、身體凹、回正 |
| B4 | **受力分級** | 依「武器力道 × 霧屍重量」分三級：**輕**＝原地後仰＋推 4 px；**中**＝受擊影格＋往後滑行並揚塵；**重**＝擊飛（拋物線飛起 → 落地彈一次 → 滑行 → 倒地 0.8 s → 爬起） |
| B5 | **擊飛影格**（需要新美術） | 每種霧屍：飛起 2 格、落地 2 格、爬起 4 格 |
| B6 | **撞人（保齡球）** | 被擊飛的霧屍撞到路徑上的其他霧屍：對方小傷害＋輕受力，最多連鎖 3 隻 |
| B7 | **撞牆／路障彈回** | 擊飛撞到路障或畫面邊緣時反彈並多停一拍 |

鋁棒的定位（打飛、打暈、控場）正好對應「重」級：一般霧屍吃鋁棒是中，收尾或打到硬直中的霧屍升級成重。

### C. 畫面與聲音

| # | 做法 | 說明 |
| --- | --- | --- |
| C1 | **大型衝擊閃光** | 命中點 2–3 幀的白芯星形閃光（鈍器）／斬線（刀類），比現在大 1.5 倍、時間更短 |
| C2 | **重擊鏡頭** | 重級命中：鏡頭放大 1.04 倍 80 ms 再回彈，背景壓暗 1 幀 |
| C3 | **最後一隻慢動作** | 一波最後一隻被擊殺：0.3 倍速 0.4 秒 |
| C4 | **聲音分層與卡肉同步** | 揮空「咻」、命中「砰」＋肉聲；卡肉期間聲音不停（聲音照常播，畫面停才有重量感），重級加低頻悶響 |

### D. 建議數值（鋁棒，實作後依手感調）

| 項目 | 輕 | 中 | 重 |
| --- | --- | --- | --- |
| 卡肉 | 50 ms | 70 ms | 110 ms |
| 受擊抖動 | ±1 px | ±2 px | ±3 px |
| 擊退 | 4 px | 滑行 24 px | 飛 40–60 px、高 14 px |
| 硬直 | 0.2 s | 0.5 s | 倒地 0.8 s＋爬起 0.5 s |
| 鏡頭 trauma | 0.08 | 0.14 | 0.25＋放大 |

## 4. 美術需求（交給本地 Claude Code 用 H3 做）

只先做一般霧屍，驗證手感後再擴到其他種類。全部沿用阿凱的規格（舊版形象風格、腳底對齊、無背景）。

| 動作 | 格數 | 說明 |
| --- | --- | --- |
| zombie hit | 3 | 頭往後甩 → 身體凹 → 回正 |
| zombie knockdown | 4 | 飛起 2（身體後仰離地）、落地 2（著地、彈一下） |
| zombie getup | 4 | 趴地 → 撐起 → 站起 |
| 阿凱 melee | 6（已有） | 標記第 3 格為命中格即可 |

這一批正好適合試「一段影片串多個動作」：首幀＝霧屍站姿、尾幀＝霧屍站姿，提示詞「被重擊打飛、落地、爬起來」，一次生成擊飛＋落地＋爬起。

## 5. 進度

第一步（純程式）已完成，手感方向參考 CAPCOM 動作遊戲：
- A1 命中格定格：打中後阿凱停在球棒打到的那一格（`MeleeSystem.pose.contact` → `Player.setMeleePose`）
- A2 打中收招 ×0.75、收招過半可直接再揮；揮空收招 ×1.15（`HIT_RECOVERY`）
- B1 卡肉只有被打的霧屍抖（輕 1／中 2／重 3 px），攻擊者定格（`Zombie.hitShake`）
- B2 閃白 60 ms → 轉紅 80 ms → 回正
- B4 受力分級：處決或收尾＝重，打飛（`Zombie.launch`：拋物線 → 落地彈一次 → 躺著滑 → 倒地 0.8 s → 爬起）；空中追打只小彈一下
- B6 被打飛或高速滑行的霧屍撞倒路徑上的霧屍（最多 3 隻、不致死）
- C1 鈍器衝擊光加大：白芯閃光＋星芒＋往打擊方向噴的速度線
- C2 重擊推鏡：鏡頭以畫面中心放大 1.05 倍、90 ms 彈回（`CameraFeel.punch`）

## 6. 實作順序

1. **先做不需要新美術的部分**：A1、A2、A3、B1、B2、B4（先用現有影格＋程式拋物線）、B6、C1、C2——驗證手感，錄前後對比。
2. 本地生成霧屍 hit／knockdown／getup 影格。
3. 接上 B3、B5，換掉程式化的傾斜與轉 90°。
4. 細調數值、加 C3、C4。

每一步都錄同一段操作（連續揮擊三隻、收尾擊飛）的前後對比 GIF 驗收。

## 更新：打擊不晃鏡頭

試玩回饋：全畫面晃動、推鏡太刺眼也會暈。現在近戰打中霧屍、打中道具、開槍、霧屍被打飛落地和撞倒別隻，都不再震鏡頭、不推鏡、不放大。力道改成全靠卡肉、被打的那隻原地抖、主角身體的壓扁與反震、揚塵和音效。被霧屍打到時鏡頭只輕晃一下（trauma 0.5 → 0.2），紅色邊框也淡很多。爆炸（油桶、腫脹霧屍）仍然會晃。

## 更新：手機打擊卡頓、特效寫實化

**卡頓的原因**（桌機 CPU 量測，手機約慢 3–5 倍）：

| 原因 | 修改前 | 修改後 |
| --- | --- | --- |
| 第一次打斷手、斷腳、爆頭時，才臨時把該外觀的霧屍貼圖逐像素切成斷肢版本（每個像素都重掃整格找中心） | 打擊那一幀 250–600 ms | 中心／褲頭位置每格只算一次，切一張約 2–8 ms；霧屍一出場就排進背景佇列，用空檔分段切好（`warmGore`） |
| 第一次播某個音效（殭屍死亡、爆裂聲）時才合成，而且一次算完全部變體 | 10–75 ms | 解鎖音效後依「戰鬥常用」優先、每次只算一個變體在背景預熱；來不及時只當場算一個變體 |
| 跳字（爆頭、處決）每次新建文字物件、重畫文字貼圖；連擊數每下重畫兩次 | 每次 1–3 ms＋上傳 GPU | 跳字物件池、常用字預先建好；連擊數顏色沒變就不重設 |
| 煙、灰塵、血霧每次新建圖片 | GC 停頓 | 物件池 |
| 卡肉疊加上限 170 ms，幀率低時像「打下去卡住」 | 最多 170 ms | 上限 110 ms，各項加成減少 |
| 手機畫布 4 倍解析度（2560×1440） | 填滿率吃緊 | 觸控裝置最多 3 倍 |

打擊那一幀的最長耗時：修改前 347–893 ms，修改後約 11–25 ms。

**特效寫實化**：拿掉鈍器的白色星芒、衝擊環、速度線，刀類的白色斬線，以及打在肉上的黃色火花（火花只留給打在護甲、金屬上）。改成：
- 刀類：沿著刀的去向甩出一道細細的血；重砍多一小團血霧
- 鈍器：一小團暗紅血霧＋少量血滴＋一點揚塵
- 槍擊：往射出方向噴血＋一小團血霧
- 爆頭：兩團暗紅血霧往子彈方向散開（不再是亮紅色實心圓）
- 血色改暗、低彩度；大血滴飛得慢、飛不遠
- 揮擊軌跡只留兩條很淡的武器本色細線、只畫揮到的那一端、80 ms 消失
- 受擊擠壓變小（18% → 7%）
