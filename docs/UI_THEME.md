# UI 主題：鏽鐵像素風

所有介面都從 `src/ui/theme.ts` 畫，不要再直接用 `add.rectangle` 加白色描邊當面板或按鈕。

| 元件 | 用法 |
| --- | --- |
| 面板（對話框、資訊卡） | `uiPanel()`（`src/explore/ui.ts`）或 `drawPanel(g, …)`：外黑線＋2 像素斜面鐵框＋四角鉚釘，內容從 x+5、y+5 開始放 |
| 按鈕／選項 | `uiButton()`：鐵片底板，滑過變亮、按下往下沉 1 像素；`accent` 給選中狀態 |
| 頂端資訊列 | `uiTopBar()` |
| 血條 | `PixelBar`／`uiBar()`：分格、掉血留白色殘影、低於 25% 閃爍 |
| 圖示 | `icon(scene, x, y, 'heart')`，圖示是 `theme.ts` 裡的字元點陣，新增一個就多一張 `ui_ic_<名稱>` 貼圖 |

## 戰鬥畫面不放面板，狀態回到角色身上

原本左上的主角面板＋小隊面板佔了約 180×110，正好壓在路障、夥伴站位與多樓層據點的頂樓上。
現在戰鬥中畫面角落幾乎是空的，資訊改畫在它所屬的東西身上：

| 資訊 | 畫在哪 | 程式 |
| --- | --- | --- |
| 生命 | 主角腳下的光圈：血越少越小越暗，低於 35% 轉紅、閃爍，角色本身染血變淡；30% 以下心跳紅邊（`ScreenFeedback`） | `src/ui/HeroStatus.ts` |
| 體力 | 腳下前半圈的藍色弧線，滿了就淡出；見底閃紅 | `src/ui/HeroStatus.ts` |
| 噪音（探索） | 從主角身上擴散的聲波圈，越吵越大、越紅 | `src/ui/HeroStatus.ts` |
| 彈藥 | 準星右側一排彈匣格（大彈匣是直條＋數字），換彈是準星外一圈進度；備彈快沒了才顯示 | `src/ui/AimReadout.ts` |
| 武器名 | 換槍／切近戰時在準星（近戰時在頭上）上方浮出一秒多 | `src/ui/AimReadout.ts` |
| 近戰連段、被抓住 | 主角頭上的小格與字，打完淡掉 | `src/ui/AimReadout.ts` |
| 路障、夥伴 | 受損時頭上才出現小血條 | `Barricade`、`Companion` |
| 據點 | 被打時那一側的畫面邊緣泛紅；耐久低於 35% 一直微微泛紅 | `UIScene` |

## 夜晚戰鬥 HUD（`src/scenes/UIScene.ts`）

- 上方中央只有一行「第 N 夜」＋波次格，沒有底板
- 右上暫停鈕（電腦旁邊標 Esc）
- 觸控右下：換彈、持刀／持槍、醫療，帶兩把槍以上多一顆「換槍」（馬克多擊倒、帶巴雷特多狙擊鏡）；平時 70% 不透明，按下才全亮
- 電腦右下：醫療 H、技能 C 兩個快捷格
- 小隊指令（F）切換時上方跳一行短提示

### 暫停畫面（Esc／Tab，觸控點右上 ❚❚）

完整資訊收在這裡：左邊選單（繼續、小隊固守／跟隨、音效、教學中可跳過教學），
右邊四格依序是主角（生命、體力、技能、醫療包）、武器（帶上場的槍與近戰，目前彈匣與備彈）、小隊（每人血量與狀態）、據點（據點、路障、廢料、擊殺）。
畫面壓暗 80%，四格用 1px 細線分區。
