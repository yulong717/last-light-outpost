# UI 主題：鏽鐵像素風

所有介面都從 `src/ui/theme.ts` 畫，不要再直接用 `add.rectangle` 加白色描邊當面板或按鈕。

| 元件 | 用法 |
| --- | --- |
| 面板（對話框、資訊卡） | `uiPanel()`（`src/explore/ui.ts`）或 `drawPanel(g, …)`：外黑線＋2 像素斜面鐵框＋四角鉚釘，內容從 x+5、y+5 開始放 |
| 按鈕／選項 | `uiButton()`：鐵片底板，滑過變亮、按下往下沉 1 像素；`accent` 給選中狀態 |
| 頂端資訊列 | `uiTopBar()` |
| 血條 | `PixelBar`／`uiBar()`：分格、掉血留白色殘影、低於 25% 閃爍 |
| 圖示 | `icon(scene, x, y, 'heart')`，圖示是 `theme.ts` 裡的字元點陣，新增一個就多一張 `ui_ic_<名稱>` 貼圖 |

## 夜晚戰鬥 HUD（`src/scenes/UIScene.ts`）

- 左上主角面板：生命、體力、手上的武器（圖示＋名稱＋一顆顆子彈的彈匣；近戰時是連段格＋下一招名稱）、武器槽
- 左上面板下方「小隊」：夥伴血條；點標題列切換固守／跟隨（電腦 F）
- 上方中央夜牌：第幾夜、波次格、據點與路障耐久
- 右上：廢料、擊殺、靜音
- 觸控右下只留：換彈、持刀／持槍、醫療（馬克多一顆擊倒）。換下一把槍＝點左上武器欄
- 電腦右下只留醫療 H、技能 C 兩個快捷格，其他看鍵盤

武器資訊原本放在畫面中下方，容易被當成地上的道具，也擋到戰場；現在併進左上面板。
