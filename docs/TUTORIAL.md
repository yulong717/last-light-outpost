# 開局教學戰鬥

新遊戲的流程：選據點 → 選主角 → **序章 → 開局教學戰鬥** → 第一天白天（第一章開場）。

教學就在自己選的據點前打，用主角自己的起始武器，一步一步帶過基本操作，最後清掉一小波霧屍。

| 步驟 | 電腦 | 手機（黃框閃爍提示） | 過關條件 |
| --- | --- | --- | --- |
| 先走兩步 | WASD／方向鍵 | 左下搖桿 | 走一小段距離 |
| 開槍 | 滑鼠瞄準、左鍵 | 點住右半邊畫面 | 打倒 2 隻（一次放一隻） |
| 換彈 | R | 「換彈」 | 開始換彈（彈匣是滿的會先倒掉一些） |
| 近戰 | 4／X 切近戰模式、左鍵揮（右鍵／V 快揮） | 「持刀」，點畫面揮 | 近戰打中 3 次（翻出路障打） |
| 換槍 | Q／1／2 | 「持槍」回到槍，點左上武器欄換下一把 | 換一次（只有兩把槍的馬克才有這步） |
| 守住據點 | — | — | 清光練習波（5 隻平民＋1 隻跑者） |

- **身上沒有槍**（阿凱開局只有球棒）：跳過開槍、換彈、換槍，近戰那步改成球棒版文字、打中 4 次，最後一波只有 4 隻平民霧屍
- 教學中主角**不會倒下**（`Player.minHp = 1`，血太少會自動補），專心練操作
- 打完會**還原**子彈、醫療包／手雷、路障與據點耐久；擊殺掉的廢料保留，當作見面禮
- 右上「跳過教學」或 Esc 可以直接跳過；`GameState.data.tutorialDone` 記錄打過了
- 步驟文字與練習波在 `src/data/tutorial.ts`，流程在 `src/systems/Tutorial.ts`，
  `DefenseScene` 用 `{ tutorial: true }` 啟動，提示框與按鈕閃框在 `UIScene`
- 近戰模式（#27）已接上：近戰那步閃框提示「持刀」鍵；沒槍時提示直接點畫面揮
